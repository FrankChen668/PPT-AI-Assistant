# Icon Assets

Static icon assets for SVG authoring live here.

- Library path: `assets/icons/element-plus/`
- Index file: `assets/icons/icons_index.json`

Executor reference convention (in SVG):

- `data-icon-ref="element-plus:warning"`
- `<!-- icon_ref: element-plus:warning -->`

QA can resolve these IDs against `icons_index.json` and emit warning when missing.
